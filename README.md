# 🛍️ ShopEase – Online Shopping Landing Page

ShopEase is a simple and responsive e-commerce landing page built using HTML and CSS. It features a navigation bar, hero section, featured products, and an about section.

## 🚀 Technologies Used

- HTML5
- CSS3

## ✨ Features

- Responsive navigation bar
- Attractive hero section
- Featured product cards
- Hover effects and smooth transitions
- Responsive layout for mobile, tablet, and desktop
- Clean and simple UI
