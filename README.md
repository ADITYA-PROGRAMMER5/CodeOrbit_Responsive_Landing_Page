# 🛍️ ShopEase – Online Shopping Landing Page

ShopEase is a simple and responsive e-commerce landing page built using HTML and CSS. It features a navigation bar, hero section, featured products, and an about section.

## 🚀 Technologies Used

- HTML5
- CSS3

## ✨ Features

- Responsive navigation bar
- Attractive hero section
- Featured product cards
- Hover effects and smooth transitions
- Responsive layout for mobile, tablet, and desktop
- Clean and simple UI

## ⚙️ Setup Instructions

1. Clone the repository:

   ```bash
   git clone https://github.com/ADITYA-PROGRAMMER5/CodeOrbit_Responsive_Landing_Page.git
   ```

2. Open the project folder:

   ```bash
   cd ShopEase
   ```

3. Open `index.html` in your browser.

That's it! The project is ready to use.
